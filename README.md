# 海鸥思维 · Seagull Thinking

> 看广告，拆商业模式；听音乐，把日子过成节奏。

一个只属于你自己的安卓 App：每天叼几条广告回来，把人群、场景、需求、卖点、痛点、商业模式一条条拆开；再去「明志」墙上写一句话，选一个音乐模式，把该干的事干完。

**纯本地运行，不联网同步，不需要注册账号。**

---

## 四个模块

### 1. 搞薯条（首页）

- 一只叼着薯条的海鸥从画面外飞进来，站在枝头；点它，开始今天的广告
- 广告来源三选一：**内置示例广告** / **手机里的视频** / **网页链接**
- 看完广告，弹出分析表单，按你定义的顺序一条条问：
  - 人群 → 场景 → 需求 → 卖点 → 产品痛点 → 商业模式 → 个人心得
  - 每写完一条点「下一步」，这一条收起、下一条展开；可随时「上一步」回去改
  - 分析点可以自己增删改、调顺序
- 每一笔记录都存两个时间戳，精确到秒：**看完广告的时间**、**写完分析的时间**
- 每天目标 1–50 条可调，默认 3 条

### 2. 明志

- **明志墙**：自己写的语录，位置可以拖到墙上任意地方（按比例保存，换手机也不跑位）
- **音乐模式**：每个模式一张圆形封面（可自定义），里面放你自己的歌
- 导入方式：
  - 从手机本地多选音频
  - **粘贴 B 站 BV 号**，自动解析并下载音频到本机
- 播放器：播放全部、单曲循环、列表循环、随机播放、定时停止（15/30/45/60 分钟或「播完这首就停」）
- 统计：每首歌**完整听完**才计一次，同时累计收听时长

### 3. 记录

- 按日期归档，顶部点日期可跳转到任意一天
- 列表从中线向上下两端展开，约占屏幕三分之二
- 点开一条，展开三块：
  1. **广告内容**：标题、来源、看完的精确时间
  2. **分析**：每一项分析内容 + 写完分析的精确时间
  3. **随笔**：默认空白，写完保存，显示内容与时间

### 4. 设置

- **个性化**：浅色 / 深色 / 跟随系统、6 种主题色、自定义背景图、系统/衬线/等宽字体、字号缩放、卡片圆角
- **薯条计划**：每日条数、广告来源开关、分析点自定义、B 站 Cookie（可选）
- **存储与导出**：数据概览、选择导出目录、导出 JSON（完整备份）/ CSV（丢进 Excel 复盘）、清空数据

## 安装

1. 打开 [Releases](../../releases) 下载最新的 `seagull-thinking-vX.X.X.apk`
2. 传到手机点击安装，允许「安装未知来源应用」
3. 首次进入即为完整功能，无需任何配置

最低支持 **Android 8.0（API 26）**。

## 自己构建

```bash
# 需要 JDK 17 与 Android SDK（platform 34 / build-tools 34.0.0）
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

也可以直接推送 tag，GitHub Actions 会自动构建并发布：

```bash
git tag v1.0.0 && git push origin v1.0.0
```

## 技术栈

| 层 | 选型 |
|---|---|
| UI | Kotlin + Jetpack Compose（Material 3） |
| 数据 | Room（广告记录 / 分析项 / 语录 / 音乐模式 / 曲目） |
| 设置 | DataStore Preferences |
| 播放 | Media3 ExoPlayer |
| 网络 | OkHttp + Gson |
| 图片 | Coil |

代码结构：

```
app/src/main/java/com/qionevale/seagullthinking/
├── data/          实体、DAO、数据库、播放器、B站解析、导出
└── ui/            主题、四个 Tab、广告会话、记录、设置
```

## 数据与隐私

- 所有记录、语录、音频都保存在应用私有目录（`/data/data/com.qionevale.seagullthinking/`）
- App 不请求存储权限，选图选歌走系统文件选择器
- 不收集任何统计信息，无第三方 SDK 埋点
- 唯一的外网请求是 B 站音频解析（只在你自己点「导入」时发生）

## 关于 B 站导入

- 实现方式：`x/web-interface/view` 取 cid → `x/player/playurl` 取音频流 → 下载为 `.m4a` 存到本机
- B 站有风控，部分视频需要登录态。可在「设置 → 薯条计划 → B 站 Cookie」填入浏览器里的 `SESSDATA` 再试
- 下载的音频**仅供个人学习使用**，请尊重原作者版权，不要二次分发
- 该功能可能因 B 站接口调整而失效，失效时请用「本地文件」导入

## 签名说明
